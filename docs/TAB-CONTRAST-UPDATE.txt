ViPER for Linux — high-contrast tabs (option 3)

This is a complete copy of the previously delivered seven-effect,
Android-inspired GUI release, with ONLY the tab bar styling changed.

* Active tab: dark teal (#236e76), white label, as with enabled effect switches.
* Inactive tab: quieter light gray/blue (or dark-theme equivalent).
* Slightly larger, padded tab labels; rounded backgrounds.
* Enhancements and Surround tabs and all seven effects remain.
* No LADSPA, DSP, controls, routing, presets, or settings changes.

Safe evaluation on Arch:
  - Keep your currently working project directory untouched.
  - Extract this entire archive into ~/Desktop.
  - cd ~/Desktop/viper-for-linux-seven-effects-teal-tabs
  - ./install.sh
  - With the existing backend still running, close ONLY its current GUI.
  - Run ./gui.sh in THIS directory to test the redesigned tabs.

The Qt GUI connects to the same shared-memory backend control channel.
Because the DSP control protocol is unchanged, you do NOT need to stop or
restart the working backend just to try the new tab styling. However,
do not run BOTH backends simultaneously.  Don't run this new start.sh
while your original backend is already running.

To revert, simply close the new GUI and reopen the original GUI.
No audio processing settings are intentionally changed by the styling.

Test status:
  Seven-effect DSP mock suite and static UI checks pass in the packaging
  environment; native Qt6 compile and visual test require your Arch system.
