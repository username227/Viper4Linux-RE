# Output-first tab order (GUI-only)

The tabs now appear Output → Enhancements → Surround. The selected tab is stored by its name; existing numeric tab-state keys are ignored to prevent showing a different category after reordering. Initial display is Output.

No DSP engine, control protocol, routing, startup, preset, effects, or command-line source was changed. Build and launch **only the new GUI** against the existing output-controls backend if it is still running.
